# Uçak modelleri

`pa28.glb` (Piper PA-28) ve `b737.glb` (Boeing 737) — Flightradar24 3D modelleri
(https://github.com/kalmykov/fr24-3d-models), aslı FlightGear projesi (https://github.com/FGMEMBERS).
Lisans: **GNU GPL v2** (bkz. `LICENSE-GPLv2.txt`). glTF 1.0'dan 2.0'a gltf-pipeline ile çevrildi; başka değişiklik yok.

Not: GPL varlıklar App Store dağıtımıyla uyumsuz sayılabilir; mağaza sürümü için CC0 veya kendi modellerimizle değiştirilmeli.
